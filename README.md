# Assistant 3.0

A full-stack AI-powered web assistant built with Python, Flask, HTML, JavaScript, and CSS — developed and iterated across multiple versions.

---

# Overview

Assistant 3.0 is an intelligent web-based assistant that leverages AI APIs to provide smart, conversational responses through a clean and responsive user interface. This project represents the third major iteration of the assistant, reflecting continuous improvement in both functionality and design.

---

# Features

- Conversational AI interface powered by AI APIs
- Full-stack web application (frontend + backend)
- Clean, responsive UI built with HTML, CSS, and JavaScript
- Fast backend powered by Python and Flask
- Continuously improved across 3 major versions

# How to Run Locally

```bash
# Clone the repository
git clone https://github.com/yaalasan/assistant3.0.git
cd assistant3.0

# Install dependencies
pip install -r requirements.txt

# Run the app
python app.py
```

Then open your browser and navigate to `http://localhost:5000`
